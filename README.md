# Martian Frontend Test Project

It is a role-play test project where you need to play the role of a Martian assigned to a new project. Your hiring interviewer will play the role of the client (who, as usual, speaks unclearly and has fuzzy requirements).

The test contains 2 steps:

1. **Understand the task and create a plan:** You need to interview the client to find out the true background and goals for the project. Then you will need to create ideas to solve the problem and explain them to the client.
   * Remember, you are not a regular developer, but a consultant who helps the business, not just solving direct tasks. Try to think out-of-the-box.
   * Don’t rush with starting to write a code. Investigate the task properly.
   * Don't waste too much of their time. When voicing a problem, immediately offer your solutions. Try to ease their pain and offload as much work from them as possible.
   * Email is not Slack; try to combine multiple messages into one letter.
   * A drawn (in Figma or just on a napkin) prototype is better than a verbose description.

2. **Writing the code:**
   1. Tell the client the deadline and the time in hours it will take to complete the task *(spoiler: we don’t care how much time it'll take, honestly)*.
   2. You can use an LLM if you want; just document well how exactly you used it.
   3. Once you’ve finished, we expect:
      * A PR with highlights of every small detail you are proud of;
      * The app deployed to any free cloud like Netlify.
   4. Email the client that you’ve finished and provide the link.

Other matrians will review conversation and code later. If you need Google Docs or any resource by link, create it with “access by link” access and do not remove until the end of the review.

## Task

The quick note from the client about the problem:

> We need an OKLCH color picker for blind people. And it should not be ugly for sighted people.
>
> Feel free to use any stack. Choose what fits the task best, not just what’s popular.

The context: You were assigned to the project and, as on any Martian project, you work together with the client to solve the problem.
